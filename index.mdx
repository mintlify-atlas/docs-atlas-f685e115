Arcature is a full-stack web framework for Rust. One crate and one `cargo add` gets you HTTP routing, the Inertia.js protocol, a database layer, authentication, validation, background jobs, events, cache, storage, mail, and the `arc` command-line tool. It integrates proven components — Axum, Tower, Tokio, SeaORM, SQLx, OpenDAL, lettre, tracing — and owns what sits between them: the application lifecycle, the request pipeline order, the conventions, and a coherent vocabulary.

## What makes Arcature different

<CardGroup cols={2}>
  <Card title="One crate, one port" icon="box">
    `arc dev` serves the backend and Vite together on a single TCP port. No `localhost:5173` to juggle.
  </Card>
  <Card title="Client Exposure Firewall" icon="shield-check">
    Only types marked `#[page]` or `#[resource]` can reach the browser. Accidental leaks are compile errors.
  </Card>
  <Card title="No hidden registry" icon="eye-slash">
    No `TypeId` maps, no thread-locals, no `inventory`. All metadata is `&'static` const data — `cargo expand` shows everything.
  </Card>
  <Card title="TypeScript code generation" icon="code">
    `arc typegen` writes typed route helpers, page prop types, and form rules from the application graph.
  </Card>
</CardGroup>

## Quick install

<Steps>
  <Step title="Download the arc CLI">
    Grab the archive for your platform from the [releases page](https://github.com/ArcatureLabs/Arcature/releases/latest), unpack it, and put `arc` on your `PATH`. Linux, macOS, and Windows binaries are available for x86-64 and arm64.

    Or compile from source:
    ```bash
    cargo install arcature --features cli --locked
    ```
  </Step>
  <Step title="Scaffold a new project">
    ```bash
    arc new my-app
    cd my-app
    ```
    `arc new` generates the project structure, mints `APP_KEY`, installs npm dependencies, and configures SQLite — no server or container needed.
  </Step>
  <Step title="Start the dev server">
    ```bash
    arc dev
    ```
    The dev loop applies migrations, builds the Rust binary, and serves both the backend and Vite on a single port. Open [http://127.0.0.1:1183](http://127.0.0.1:1183).
  </Step>
</Steps>

<Note>
  Arcature requires **Rust 1.97.1+** (edition 2024) and **Node.js** for the frontend. SQLite is the default database — no server required to get started.
</Note>

## Architecture at a glance

Arcature's `default` feature set is a complete full-stack application with no extra flags. Optional subsystems like `otel`, `api-docs`, `oauth`, and `storage-s3` are disabled by default — they add real cost (crates, migrations, or attack surface) that builds not using them should not pay.

| Subsystem | Built on | Feature |
|---|---|---|
| HTTP routing | Axum 0.8, Tower 0.5 | always on |
| Inertia.js v3 server | protocol, implemented directly | `inertia` |
| Database | SeaORM 2.0 + SQLx 0.9 | `database` + `db-*` |
| Auth, sessions, CSRF | argon2, tower-sessions | `auth` |
| Jobs queue | database-backed, dialect-specific claim | `jobs` |
| Realtime | WebSocket + SSE | `realtime` |
| Observability | tracing, Prometheus, W3C trace context | `observe` |
| The `arc` CLI | clap 4 | `cli`, `templates` |

See [Features reference](/reference/features) for the complete list.
